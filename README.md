# Hi, I'm Razi

I build small desktop tools that keep your data on your own computer, and I teach beginner web development on YouTube. I live in Vancouver, BC, and speak English and Persian.

**YouTube:** [Tech with AK47](https://www.youtube.com/@techwithak47) · **Email:** rzk.karimi@gmail.com

## What I build

- **Tray and menu bar apps** for Windows, Linux and macOS, built with Tauri and Rust, plus two Mac-only versions in Swift and Python.
- **Local-first tools:** no accounts and no analytics. The money apps make no network requests at all.
- **Beginner lessons** with practice assignments you can download and check yourself.
