## Tray and menu bar apps (open source, MIT)

| App | What it does | Platforms |
|---|---|---|
| [Money Bar](https://github.com/RezzAk47/money-bar-cross) | Daily spending, wages and tips. No network, no accounts. | Windows, Linux, macOS (Tauri) |
| [Agents Bar](https://github.com/RezzAk47/agents-bar-cross) | Shows your running and finished Claude Code and Codex agents and GitHub CI. | Windows, Linux, macOS (Tauri) |
| [Usage Bar](https://github.com/RezzAk47/usage-bar-cross) | Shows Claude Code and Codex usage limits. Unofficial. | Windows, Linux, macOS (Tauri) |

The original Mac-only versions: [money-bar](https://github.com/RezzAk47/money-bar) (Swift) and [agents-bar](https://github.com/RezzAk47/agents-bar) (Python). Agents Bar and Usage Bar are based on [CLI-Usage](https://github.com/nimaansari/CLI-Usage) by Nima Ansari (MIT).

All of these are early. They build and pass tests on Windows, Linux and macOS in CI; I have mostly used them on a Mac, and the builds are unsigned.
